# ADR-006: Grading unit — link-level primary, group and row secondary

## Status
Accepted

## Context
PLAN.md's `match_rate` denominator was undefined. The precision/recall unit was unspecified — was it triple-level, link-level, or row-level? The "4x4 confusion matrix" was meaningless for binary link decisions (D6, R5, R8).

## Decision
Three levels, all reported together (§4.1):

| Level | Unit | Primary metric |
|-------|------|----------------|
| Link | candidate pair `(bank,payout)` or `(payout,ledger)` | precision, recall, F1 per link type |
| Group | truth group | `match_rate` = groups exactly correct / truth groups |
| Row | source record | `resolved_rate`, `unresolved_rate` |

Link level is primary (real confusion matrix). Group level is the honest headline. Row level is what finance asks.

Every metric serialized as `{value, numerator, denominator}`. A bare float fails schema validation (I11).

## Consequences
Every number has a defined denominator. Precision is interpretable over the candidate space C (§4.2).
