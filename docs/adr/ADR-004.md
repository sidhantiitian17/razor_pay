# ADR-004: MatchGroup replaces MatchTriple — link-level grading

## Status
Accepted

## Context
`MatchTriple(bank_id?, payout_id?, ledger_id?)` was strictly 1:1:1. Duplicate payouts (1 bank : 2 payouts) and refund pairs (2 offsetting ledger entries) were unrepresentable (D4, C4). This made grading undefined for 10% of the batch.

## Decision
- `MatchGroup { bank_ids: list, payout_ids: list, ledger_ids: list, kind: GroupKind, ... }`
- `GroupKind` enum with cardinality invariants (I8)
- Grading at **link level**: bipartite edge decisions `(left_id, right_id, predicted, truth, outcome)`
- Group-level `match_rate` requires set equality on all three ID lists **and** correct kind
- `partial_group` bucket catches overlapping but non-equal predicted groups

## Consequences
N:M cases grade naturally. The grading unit is precisely defined (§4.1).
