# ADR-001: Timing bucket split into tolerated and exception cohorts

## Status
Accepted

## Context
PLAN.md injected date skew of ≤2 days, but the match tolerance was also ≤2 days. Every timing row matched and never reached the classifier, making the `timing` bucket unreachable (D1, C1).

## Decision
Split into two cohorts:
- `skew_tolerated`: inject +/- [1,2] days → resolved, tag `timing_tolerated`
- `skew_exception`: inject +/- [3,5] days → unresolved, bucket `timing_break`

## Consequences
The `timing_break` bucket is now reachable. Both cohorts map to exactly one terminal state.
