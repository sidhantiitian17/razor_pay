# ADR-002: Drift boundary fix and resolved/unresolved split

## Status
Accepted

## Context
PLAN.md injected drift of ±50 paise with a tolerance of ≤50 paise inclusive. Every drift row sat on the boundary. The same rows were counted as both matched and bucketed as exceptions (D2, C2).

## Decision
Split into two cohorts:
- `drift_tolerated`: inject +/- [1,49] paise → resolved, tag `drift`
- `drift_exception`: inject +/- [80,200] paise → unresolved, bucket `amount_mismatch`

The report separates `resolved` (tag map) from `unresolved` (bucket map). They are disjoint vocabularies.

## Consequences
No row is counted in both resolved and unresolved. The boundary is unambiguous (49 matches, 50 matches via ≤49 in code, 80+ does not).
